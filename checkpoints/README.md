# 模型文件

这里保存优化与评测所需的模型权重及其配套资产，按“模型 → 固定版本”组织。

## 组织形式

```text
checkpoints/
├── README.md
├── moss-speech/
│   └── <revision>/
│       └── <模型原始文件>
└── <其他需要的模型>/
    └── <revision>/
        └── <模型原始文件>
```

上面的模型目录仅为组织示例，目前尚未下载模型。

- 模型目录保留下载来源的原始文件布局，包括实际需要的权重、配置、tokenizer 等配套文件。
- `<revision>` 使用来源提供的固定版本或完整 commit；登记来源支持的不可变标识，避免仅以 `main` 或 `latest` 作为版本依据。
- 同一模型的不同版本并列保存；运行配置引用具体版本目录。

## 转换与量化产物

转换或量化后的权重单独保存，保留原始模型版本。产生此类文件时，在本 README 中登记对应目录，并记录原始来源及版本、转换工具及版本、转换命令和输出格式或精度；具体目录命名按实际转换方式确定。
