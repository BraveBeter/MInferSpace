# 运行配置

可复用配置按用途放在 `server/`、`benchmark/`、`profile/` 等实际需要的子目录中，沿用相应工具的原生格式。在 [PROJECT.md](../PROJECT.md) 或相关任务中链接采用的配置和入口命令。

- 相对路径按所用工具的规则解析，核对它们指向已登记的模型、数据、源码和环境。
- 每次运行在对应的 `execution/` 中留存实际配置、命令、参数和覆盖设置。重跑时核对留档副本的路径解析。
- 凭据由外部环境提供，记录所需变量名。
