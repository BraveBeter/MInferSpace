# 任务记录与收尾

适配和优化统一在本目录登记。适配使用 `ADP-0001` 等编号，优化使用 `OPT-0001` 等编号。每种编号独立递增，历史编号继续保留。

## 建档

- 从 [任务模板](_template.md) 创建 `tasks/<任务编号>-<名称>/task.md`，例如 `tasks/ADP-0001-model-support/task.md`。名称使用小写英文字母、数字和连字符。
- 任务正文保留“字段 / 值”表中的任务编号和状态，记录目标、起点完整提交、适用参考、验证条件、执行证据及结论。项目自定义字段和章节可按需补充。起点尚待确认时记录原因。
- [PLAN.md](../PLAN.md) 的“任务编号 / 任务文档”表为每项待结案任务保留一行，使用指向该任务正文的相对链接。所有状态和结论以任务正文为准。

| 状态 | 含义 |
| --- | --- |
| `planned` | 已建档，等待开始 |
| `in-progress` | 正在准备、实现、采集或验证 |
| `blocked` | 有具体依赖阻止继续，正文记录已完成的工作和所缺条件 |
| `done` | 已完成适用验证并记录结论或处置结果 |
| `cancelled` | 已结束，正文记录取消原因和已有证据 |

## 收尾检查

1. 更新任务正文中的状态、实际受测提交、验证命令与结果、证据链接、结论和未完成事项。运行失败或中断时保留现有证据。
2. 同步 [PLAN.md](../PLAN.md)。`done` 和 `cancelled` 的任务移出计划，正文继续保存。
3. 按对应目录约定登记本次实际新增或变更的工作副本、环境、权重、数据、配置、profile 和 benchmark。任务正文链接到已有记录。未采集或未验证的事项按实际状态说明。
4. 更新 [PROJECT.md](../PROJECT.md) 指定的适用文档并执行其中声明的适用收尾检查。运行 `python3 scripts/check_workspace.py`，修复检查发现的记录问题。
