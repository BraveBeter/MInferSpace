# Benchmark 结果

统一保存功能、质量和性能评测的执行材料及结果。按 `benchmark-results/<任务编号>/<UTC开始时间>-<场景>-<角色>/` 组织。角色按实际使用 `reference`、`baseline` 或 `candidate`。重新运行创建新目录，重名时追加 `-02` 等后缀；恢复运行采用工具本身的约定。

- 正式运行前核对实际加载的源码与完整提交、工作树状态、解释器、配置、模型与数据版本、设备分配。记录检查及相关异常。
- 在 `execution/` 留存命令、工作目录、环境快照引用、实际配置、输入及运行状态。评测结果保留工具原生格式，人工补充分析单独保存并引用原始证据。
- 比较前冻结输入、生成参数、指标定义和通过条件。记录可比条件、重复次数、波动、有效样本覆盖及失败情况。条件发生变化时写明差异并按可比条件补测。
- 已有对照可以跨任务引用原报告。保留失败、中断和未评分的运行记录。大产物可放在外部归档，仓库保存可定位、核验和恢复的清单。
- 将关键运行和比较报告链接到 [任务正文](../tasks/README.md)。项目专用命令、指标和产物规则由 [PROJECT.md](../PROJECT.md) 引用。

正式性能结论以可比的 benchmark 为依据。[Profile](../profile-results/README.md) 用于定位原因和核查假设。
