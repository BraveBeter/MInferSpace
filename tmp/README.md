# 临时文件

这里保存下载、解压、转换过程中的中间文件，以及一次性检查产物。仅存放可重新生成或可丢弃的内容。

## 组织方式

按 `<任务名>-<UTC时间>/` 创建临时子目录，例如：

```text
tmp/
├── README.md
├── download-20261117T120000Z/
└── convert-20261117T130000Z/
```

任务名使用简短的小写英文和连字符，时间使用 UTC。示例目录在实际需要时创建；名称冲突时追加后缀，避免覆盖已有文件。

## 使用与清理

- 复现所需的模型、数据、配置、命令、日志或证据及时移入相应正式目录，并更新相关引用。
- 临时任务完成后，可清理对应任务目录；长期保留的原始产物按正式目录的归档约定管理。
- 清理临时内容时保留本 README。

工作区的 `.gitignore` 保留本 README，忽略本目录中的其他临时内容。
