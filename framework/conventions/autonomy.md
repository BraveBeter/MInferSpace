# Agent 自主边界

| 可以自主执行 | 须先征得用户确认 |
| --- | --- |
| 创建工作项、本地 worktree 与分支、本地 commit | push、开 PR、远端评论、删除远端分支、改写已被引用的历史 |
| 在工作区内创建或更新环境 | 修改系统级环境；单次下载超过下载阈值 |
| 运行 benchmark、profile、正确性验证 | 单次 GPU 占用超过时长阈值，或违反 `PROJECT.md` 中的 GPU 使用约束 |
| 更新项目层文档、登记表、knowledge | 修改 `framework/`；修改 `PROJECT.md` 中的目标、范围或验收口径 |
| 在门禁范围内迭代实现 | 扩大工作项范围；放宽验收口径；跳过门禁 |
| 新建依赖工作项（作为提议，状态 `planned`） | 开始执行范围外的新工作项 |
| 清理 `tmp/` | 删除证据目录、模型或数据；移除仍被引用的 worktree |
| 启动独立审查 Agent | 忽略审查中的阻断级意见 |

阈值默认值见 [defaults.md](defaults.md#自主边界参数)，项目可在 `PROJECT.md` 中覆盖。

## 受阻时

1. 在 item.md 交接区写明：受阻点、已尝试的方法及证据、需要的输入或授权。
2. 状态改为 `blocked`，同步索引与 PLAN。
3. 停下来向用户汇报，不绕过访问控制、权限或环境限制。
