# 共享子流程：交付

## 决定与执行

| 决定 | 含义 | 执行条件 |
| --- | --- | --- |
| `push` | 推送分支到远端 | 用户授权 |
| `pr-open` | 已开 PR，等待合入 | 用户授权 |
| `merged` | 已合入目标分支 | 以远端记录为准 |
| `keep-local` | 只保留本地分支与 worktree | 可自主执行 |
| `discard` | 放弃实现，证据保留 | 移除 worktree 前确认无引用 |
| `n/a` | 调研类无代码交付 | — |

item.md 记录决定、理由与执行状态，例如 `push（待用户授权）`。

## PR 描述

向目标仓库开 PR 时，描述包含：动机、改动摘要、正确性证据摘要、性能证据摘要（含条件与波动）、已知限制与未支持特性、测试方式。遵循目标仓库的 PR 模板时，把以上内容填入对应栏目。

## 向用户汇报

每次交付或会话结束的汇报包含：

1. **实际改动**：仓库、分支、commit、文件范围。
2. **验证结果**：门禁、正确性、性能结论，附证据链接。
3. **审查情况**：独立审查结论与未处理意见。
4. **未完成 / 未验证事项**：没有时写“无”并说明依据。
5. **需要用户决定的事项**。

## 结项检查

- item.md 结论、决定、知识沉淀已填写；状态改为 `done` 或 `cancelled`。
- 索引更新，从 `PLAN.md` 移除。
- worktree 按决定处置并更新登记。
- `ws lint` 无错误。
