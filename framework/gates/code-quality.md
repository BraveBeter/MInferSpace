# 代码质量门禁

适用于所有产生源码改动且准备保留或交付的工作项。自审时逐项回应，独立审查时逐项复核。

- [ ] **仓库规范**：已阅读目标仓库的 `AGENTS.md`、`README.md`、`CONTRIBUTING` 及 `PROJECT.md` 列出的开发者规范，并在 item.md 中写出遵循的关键条目。
- [ ] **最小改动**：diff 只包含当前工作项必需的改动；没有调试打印、临时注释、无关格式化或顺手重构。
- [ ] **复用优先**：优先复用或继承仓库已有组件；新增模块或抽象在设计或方案中说明了必要性。
- [ ] **边界与错误**：并发、空输入、异常路径以及声明不支持的特性都有明确处理或报错，不静默产生错误结果。
- [ ] **静态检查**：通过目标仓库自带的 lint、format、类型或 pre-commit 检查（记录命令与结果）。
- [ ] **测试覆盖**：补充或更新了覆盖改动的测试（适配项含模型对比测试，修复项含回归测试），本地运行通过并留档。
- [ ] **协议与文档**：对外接口、参数与输出协议保持兼容（或已获用户批准）；行为变化有相应文档说明。
- [ ] **审查闭环**：独立审查的所有 `blocker` 意见已修复并复核，`major` 意见已修复或经用户同意保留理由。
