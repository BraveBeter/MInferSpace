# 评测数据

以 `datasets/<数据集>/<revision>/` 组织固定版本输入。将来源、固定版本、获取或转换命令、脚本版本、输出位置和必要的校验值写入准备记录。保留已有评测所引用的数据版本。

- 保留原始数据布局。预处理或清单变化时使用可区分的版本目录，记录其对应的原始版本。
- 评测配置引用实际版本。每次评测的输入清单或冻结选样随 [评测结果](../benchmark-results/README.md) 留档。
- 原始数据放在外部存储时，在仓库保留可定位、核验和恢复的记录。
